# Disease Prediction System (Healthcare Analytics)

## 📖 Project Overview
This project implements a machine learning system to predict the presence of heart disease in patients based on continuous medical data. It utilizes the **Gaussian Naive Bayes** algorithm, which is specifically designed for handling continuous numerical features like Age, Cholesterol, and Blood Pressure.

## 🎯 Objective
To assist medical professionals in early diagnosis by analyzing patient symptoms and medical history, reducing diagnostic time and improving treatment outcomes.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn (GaussianNB)
- **Algorithm:** Gaussian Naive Bayes

## 📊 Dataset
The model is trained on patient medical records containing the following features:
- **Age:** Patient's age
- **Chol:** Cholesterol level
- **BP:** Blood Pressure
- **Target:** 1 (Disease Present), 0 (No Disease)
